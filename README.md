# Tính Xây Nhà Pro V3 – Land & Construction

## Cài đặt GitHub Pages
1. Giải nén ZIP.
2. Tạo repository GitHub và tải lên 4 tệp trong thư mục này: `index.html`, `manifest.webmanifest`, `sw.js`, `README.md`.
3. Vào **Settings → Pages**. Chọn **Deploy from a branch**, branch `main`, folder `/ (root)`, rồi Save.
4. Mở URL GitHub Pages bằng Safari trên iPhone. Chọn Share → Add to Home Screen để cài như ứng dụng.

## V3 có gì mới
- Giữ các chức năng bản đồ, tìm địa chỉ, GPS, ghim tọa độ, hồ sơ thửa đất, máy tính tiền đất và dự toán xây nhà của V2.
- Thêm tab **Dữ liệu** với đầu mối nguồn dữ liệu công khai: Cổng thông tin dữ liệu nền địa lý quốc gia, cổng văn bản Chính phủ và hướng dẫn phạm vi khai thác.
- Hiển thị minh bạch tình trạng: dữ liệu nào đang hoạt động, dữ liệu nào phải tra cứu nguồn ngoài và dữ liệu nào chưa kết nối.
- Nâng phiên bản cache PWA lên V3 để tránh giữ giao diện cũ.

## Giới hạn quan trọng
Đây là V3 nền tảng, chưa phải hệ thống tra cứu địa chính/quy hoạch tự động toàn quốc. Dữ liệu thửa đất, quy hoạch và bảng giá đất phải được cung cấp/công bố bởi cơ quan có thẩm quyền hoặc qua dịch vụ/API được phép khai thác. Không suy diễn ranh giới pháp lý từ ảnh vệ tinh hoặc bản đồ nền. Giá rao bán không được coi là giá giao dịch đã xác minh.
